# Local mechanics package integration

The Agent A newer cumulative handoff supplied six source files and five tests. All eleven code blocks matched their supplied SHA-256 fingerprints before installation. Its effective-stress file and one test imported a nonexistent shared `physics-next/contracts.ts`. To compile this isolated package without asserting a global solver contract, those two type-only imports were redirected to a new `mechanics/contracts.ts` containing the exact structural grid/primary-state shape used by the proposal's fixtures. This is an integration change from the source hashes; it has no runtime behavior. The local contract is not a statement that the active coupled solver exposes or accepts that state.

The modules provide pressure/effective-stress and work accounting, finite-strain Hex8 point/element kernels, local contact, a bounded peat constitutive surrogate, and local cohesive fracture/closure. They do not assemble a global nonlinear problem, create crack topology, or feed an active solver. No parameter values are claimed calibrated to this site's peat.

Local checks on 2026-09-29: typecheck, lint, 464 targeted tests, 1,701 tests in 83 files overall, and production build passed. Lint produced non-failing warnings. Before activating any of these kernels, the coupled solver needs agreed state/energy/history semantics, mesh/interface geometry, convergence and rollback behavior, and independent physical validation. The older `index.d.ts` was reviewed as generated declaration output, not installed as overlapping code.

The separate earlier Agent A handoff also contained a provisional D/F/G mechanics boundary.
